# NMRTA: Neural Model of Reality via Temporal Active-Inference
## Reference Cognitive Architecture Prototype & Empirical Reproducibility Suite (v4)

A modular, self-contained Python reference prototype of the **NMRTA** cognitive architecture, operationalizing biological predictive processing, Global Workspace Theory, discrete-categorical world models, and high-frequency cerebellar efference copy attenuation on a continuous 2-DOF planar robotic manipulator.

---

### Scientific Scope & Experimental Architecture

This repository accompanies the manuscript *"NMRTA: A Reference Cognitive Architecture for Latent Reality Modeling via Temporal Active-Inference"* (*The Computer Journal*, Oxford University Press). Every observation in `data/*.csv` is generated by executing the dynamical simulation and neural modules across five explicit random seeds (`42, 1337, 2024, 7, 99`) without synthetic target-calibrated arrays, rescaled distributions, or hardcoded contingency counts.

To ensure strict alignment between experimental evidence and scientific claims, the four empirical evaluations in `run_full_experiment.py` are scoped as follows:

1. **Panel A — Component-Level Cerebellar Disturbance Gating (`trajectory_summary.csv`, `disturbance_events.csv`):**  
   Evaluates the 100 Hz `CerebellarForwardModel` (74-feature tensor-product Fourier-kinematic basis trained via ridge regression on 10,000 voluntary steps per seed) and reflex-gating circuit ($\tau_{\text{refl}} = 0.12$ rad/s) across a $2 \times 2$ factorial design (Movement: Voluntary vs. 10 N Perturbed $\times$ Compensation: ON vs. OFF; $N=80$ trajectories, $n=20$ per cell, 1,000 steps = 10.0 s per trajectory) driven by a continuous reference PD/feedforward trajectory controller. Logs all **1,000 discrete 10 N force pulse events** (500 in `Cell_3_Perturbed_CompON` and 500 in `Cell_4_Perturbed_CompOFF`) in `data/disturbance_events.csv`.
2. **End-to-End Integrated NMRTASystem Closed-Loop Verification (`integrated_nmrta_trajectories.csv`):**  
   Executes the complete integrated `NMRTASystem` (`ThalamicRouter` + `CategoricalRSSM` + `ToroidalGridCellMap` + `ContinuousHopfieldMemory` + `PrefrontalMPPIPlanner` + `CerebellarForwardModel`) in closed loop across all 5 seeds under both unperturbed and 10 N perturbed conditions ($10$ trajectories), verifying end-to-end multimodal routing, surprise-gated Hopfield writes, MPPI action chunking, and reflex gating ($0/500$ false trips unperturbed; $5/5$ pulses detected perturbed).
3. **Panel B — Global Workspace Feature-Bottleneck & Downstream Ridge Readout (`workspace_losses.csv`):**  
   Evaluates whether compressing $P_{\text{total}}=352$ multimodal tokens into $M=64$ Perceiver IO workspace tokens ($81.8\%$ reduction) preserves kinematic information relative to the unbottlenecked 352-token pathway when passed through the untuned `CategoricalRSSM` reservoir. For each of the $n=5$ seeds, a downstream ridge regression readout ($\lambda = 10.0$) is fit on a 45-step rollout to predict end-effector Cartesian position 15 steps ($1.5$ s) ahead, and evaluated on 4 held-out 35-step test trajectories ($N=40$ total). The recorded metric `step15_ee_pos_error_m` is the **15-step-ahead Euclidean end-effector position prediction error (in meters)**.
4. **Panel C — Multi-Session Sequential Step Latency Profiling (`latency_samples.csv`):**  
   Measures sequential single-process step execution times via `time.perf_counter()` across **3 independent benchmark sessions** with explicit warm-up and garbage-collection load controls (`1,800` total samples: `n=1,500` motor steps at 100 Hz, `n=150` integrated cognitive steps at $N_{\text{sim}}=64, H=20$, and `n=150` integrated cognitive steps at $N_{\text{sim}}=512, H=20$ on a 2-vCPU virtualized Linux x86\_64 environment), recording per-sample `session_id` and `deadline_missed`. These measurements characterize single-process component execution overhead on commodity CPU hardware rather than multi-threaded real-time OS scheduling guarantees.

### Per-Seed Breakdown of 15-Step Position Prediction Error (`step15_ee_pos_error_m`)

Because only $n=5$ top-level model seeds are evaluated, all five seed-level means (each averaging 4 held-out test trajectories of 20 prediction windows) and their paired differences are reported transparently below:

| Random Seed | 64-Token GWT Error [m] | 352-Token Unbottlenecked Error [m] | Paired Difference (64 minus 352) [m] |
|---:|---:|---:|---:|
| `7` | $0.3519$ | $0.3717$ | $-0.0198$ |
| `42` | $0.3380$ | $0.3546$ | $-0.0167$ |
| `99` | $0.4085$ | $0.4540$ | $-0.0454$ |
| `1337` | $0.2661$ | $0.2919$ | $-0.0259$ |
| `2024` | $0.3082$ | $0.2965$ | $+0.0117$ |
| **Mean $\pm$ SD ($n=5$)** | **$0.3345 \pm 0.0528$** | **$0.3538 \pm 0.0661$** | **$-0.0192 \pm 0.0206$** |

*Note on Non-Inferiority Construct & Exploratory Status:* Because no external dated preregistration protocol existed prior to simulation execution, the comparison against $\delta = 0.025$ m is reported strictly as an **exploratory post-hoc benchmark** rather than a confirmatory clinical/preregistered test. The reference scale $\delta = 0.025$ m ($2.5$ cm) represents half of the environment's $0.05$ m ($5.0$ cm) target-reaching radius (`dist_to_target < 0.05` in `environment.py`): in a receding-horizon planner using 15-step ($1.5$ s) lookahead rollouts to guide trajectories into a $0.05$ m terminal zone, keeping lookahead position prediction degradation well below half the target radius ($+0.0004$ m upper 95% bound vs. $0.025$ m) indicates that token compression does not introduce planning-relevant position drift.
